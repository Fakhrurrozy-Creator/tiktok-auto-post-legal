Privacy Policy

Application: TikTok Auto Post · Last updated: 16 September 2026

1. Who we are

TikTok Auto Post ("the App") is a personal desktop application operated by a single individual creator ("the Operator"). It runs locally on the Operator's own computer and is not offered to the public as a service. Contact: [isi alamat email kamu di sini].

2. What the App does

The App helps the Operator prepare short vertical videos from their own photos and video clips, then sends the finished video file to the Operator's own TikTok inbox as a draft, using TikTok's Content Posting API (upload-to-inbox). The Operator reviews and publishes the draft manually inside the TikTok app.

3. Data we access

  • TikTok basic profile information (scope user.info.basic): used only to confirm which TikTok account is connected.
  • Video upload permission (scope video.upload): used only to send video files created by the Operator to the Operator's own TikTok inbox.
  • Media files and text the Operator adds to the App (photos, video clips, scripts, captions).

The App does not access followers, messages, comments, analytics, or any other user's content.

4. Where data is stored

All data stays on the Operator's computer:

  • Access and refresh tokens are stored in a local file (token.json).
  • Media, scripts, and rendered videos are stored in local folders.
  • API keys are stored in a local configuration file (.env).

The App has no server, no database, no user accounts, and no analytics or tracking.

5. Data shared with third parties

  • TikTok: the video file and upload request, so the draft can reach the Operator's inbox.
  • Google (Gemini API): optional. If enabled by the Operator, script text and small preview images of the Operator's own media are sent to Google to generate topic ideas, scripts, and captions.

No data is sold, rented, or shared with advertisers or any other third party.

6. Data retention and deletion

Data is kept until the Operator deletes it. Deleting token.json removes the TikTok authorization stored locally; the Operator can also revoke the App's access at any time from TikTok's app settings. Deleting the App's folder removes all remaining data.

7. Children

The App is not intended for anyone under 18 years old.

8. Changes

If this policy changes, the updated version will be published at this same URL with a new "Last updated" date.
